Step 4 - Lock CUDA 12.4 PyTorch
--------------------------------------------------------

--------------------------------------------------------
Step 5 - Install FlashAttention & Patch Triton Bug
--------------------------------------------------------
wget https://github.com/Dao-AILab/flash-attention/releases/download/v2.8.3.post1/flash_attn-2.8.3.post1+cu12torch2.5cxx11abiFALSE-cp311-cp311-linux_x86_64.whl -P /tmp/
uv pip install /tmp/flash_attn-2.8.3.post1+cu12torch2.5cxx11abiFALSE-cp311-cp311-linux_x86_64.whl

# Auto-patch the PyTorch 2.6 Triton wrapper bug for PyTorch 2.5 compatibility
sed -i 's/torch\.library\.wrap_triton(\([a-zA-Z0-9_]*\))/\1/g' /home/OASIS/Cenv/lib/python3.11/site-packages/flash_attn/ops/triton/*.py
